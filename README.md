# Master's Thesis Summary

## Deep learning and o-minimality

Here is what can be thought of as a long abstract or a summary of my Master's thesis, which is currently a work in progress to be completed by September 2027. As the thesis will have significant applications to deep learning included, I thought it was useful to include it here.

## Contents

The topic of the thesis is essentially an application of o-minimal geometry, a subfield of mathematical logic which works with sets definable in certain "nice" structures, to the field of deep learning. I will cover certain important results in o-minimal geometry which have been used to expand the class of functions which can serve as activation functions in neural networks and retain certain convergence guarantees and well-definedness with respect to gradient descent and backpropagation. For more detail, see [thesis_summary.pdf](thesis_summary.pdf).
